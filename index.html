Process

My general workflow with AI

Five steps from idea to presented work. AI speeds up each step; design decisions stay mine.

  1. 01

    Research & planning

    ChatGPT

    Give context about the product and its users, then prioritize features and map the user flow.

    OutputBrief, priorities, user flow

  2. 02

    Competitors review

    FigJam

    Map how competitors solve the same flows: strengths, gaps and patterns worth reusing.

    OutputCompetitor map & UX gaps

  3. 03

    Visual directions

    Figma / Claude

    Explore and compare several visual directions before committing to one.

    OutputChosen direction

  4. 04

    Build

    Claude Code

    Turn the chosen design into a working app to test real interactions.

    OutputWorking prototype

  5. 05

    Present

    Gamma / Figma Slides

    Package the process and result into a clear, editable presentation.

    OutputPresentation deck
